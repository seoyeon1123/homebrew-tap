# homebrew-tap

macOS 앱 배포용 Homebrew tap.

## TokenPlant

AI 코딩 토큰 사용량으로 식물을 키우는 메뉴바 앱.

```bash
brew install --cask seoyeon1123/tap/tokenplant
```

업데이트 / 삭제:

```bash
brew upgrade --cask tokenplant
brew uninstall --zap --cask tokenplant   # --zap 은 설정 파일까지 지운다
```

저장소: https://github.com/seoyeon1123/tokenplant
